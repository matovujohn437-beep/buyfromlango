# Buy From Lango — SVG Icons

Place these files in `assets/icons/` in your Flutter project.

Included icons:
- `block.svg`
- `camera.svg`
- `chat.svg`
- `coop.svg`
- `crops.svg`
- `delete.svg`
- `emoji.svg`
- `empty_box.svg`
- `featured_badge.svg`
- `forward.svg`
- `google_logo.svg`
- `job.svg`
- `livestock.svg`
- `location_pin.svg`
- `mic.svg`
- `notification.svg`
- `phone_reveal.svg`
- `reply.svg`

Recommended Flutter setup:
1. Copy all SVG files into `assets/icons/`.
2. Add `flutter_svg` to `pubspec.yaml`.
3. Register the folder under `flutter: assets:`.
4. Load with `SvgPicture.asset('assets/icons/chat.svg')`.

The icons use a blended olive-green (`#786B36`) palette with a warm orange-gold accent (`#D9A441`).
