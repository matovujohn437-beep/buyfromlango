# Buy From Lango — SVG Illustrations

Copy these SVG files into `assets/illustrations/` in your Flutter project.

Included: empty_chat.svg, empty_listings.svg, empty_orders.svg, empty_search.svg,
error_state.svg, lango_avatar.svg, lango_coop.svg, lango_farmer.svg, offline_state.svg,
onboarding_1.svg, onboarding_2.svg, onboarding_3.svg, success_state.svg.

For Flutter rendering, add `flutter_svg` and use:
`SvgPicture.asset('assets/illustrations/lango_farmer.svg')`

These are original, editable vector illustrations using the Buy From Lango green, cream, and gold palette.
